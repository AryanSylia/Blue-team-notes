# Blue Team Notes 🧠

This repository is my structured knowledge base for cybersecurity and IT fundamentals.  
It covers the entire learning path from basic ICT concepts to Blue Team defensive operations.

---

## 📚 Structure Overview

| Section | Description |
|----------|--------------|
| **00 - ICT Fundamentals** | Basic computer and technology concepts: hardware, software, data, logic. |
| **01 - Networking** | Core networking principles, protocols, and traffic analysis. |
| **02 - Operating Systems** | Understanding Windows, Linux, processes, and system administration. |
| **03 - Programming** | Python, scripting, and automation for security and network analysis. |
| **04 - Blue Team** | Detection engineering, log analysis, SOC operations, and threat hunting. |

---

Each section contains:
- **Notes** → Study materials and summaries.  
- **Scripts** → Small tools or exercises written during learning.  
- **Detections** → Rules and practical detection content (Sigma, YARA, etc.).  
- **Resources** → Images, references, or external links.  
- **Exercises** → Practical labs or challenges.
