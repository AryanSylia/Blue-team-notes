## Introduction

Modern websites are built using three core technologies, each with a specific role in how a web page functions and appears to the user. These technologies work together to create the websites we interact with daily.

HTML is responsible for the structure of the page, CSS handles the visual appearance, and JavaScript enables interactivity and dynamic behavior. This lesson focuses specifically on HTML, the foundational language of the web.

---

## What Is HTML?

HTML stands for **HyperText Markup Language**.  
It is the language used to write the content and structure of web pages.

HTML does not control logic or behavior. Instead, it describes content and tells the browser **how that content should be displayed**. The browser reads HTML code and translates it into a visual webpage.

HTML is made up of elements, also known as tags, which are the building blocks of every webpage.

---

## Core Technologies Used in Websites

Websites are primarily created using the following technologies:

- **HTML**: Defines the structure and content of a webpage.
- **CSS**: Adds styling such as colors, fonts, spacing, and layout.
- **JavaScript**: Implements interactivity and advanced functionality.

In this lesson, the focus is entirely on HTML.

---

## HTML Elements and Structure

Every HTML page follows a standard structure. This structure is consistent across nearly all websites and helps browsers interpret and display pages correctly.

An HTML document is composed of several essential elements:

- **DOCTYPE**  
  Declares that the document uses the HTML5 standard. This ensures consistent rendering across different browsers.

- **html**  
  The root element of the document. All other elements are contained within it.

- **head**  
  Contains metadata and information about the page, such as the page title and configuration settings. Content inside the head is not directly visible to users.

- **body**  
  Contains all visible content displayed in the browser, including text, images, headings, buttons, and lists.

---

## Common HTML Elements

HTML provides many elements for structuring content. Some of the most common include:

- **h1**  
  Defines a large heading, typically used as the main title of a page.

- **p**  
  Defines a paragraph of text.

These elements help organize content logically and improve readability.

---

## HTML Attributes

HTML elements can include attributes that provide additional information or control behavior and styling.

Common attributes include:

- **class**  
  Used to group elements for styling or scripting purposes. Multiple elements can share the same class.

- **id**  
  A unique identifier assigned to a single element. IDs must be unique within a page and are often used for styling or JavaScript interaction.

- **src**  
  Specifies the source location of external content such as images.

An element may contain multiple attributes, each serving a different purpose.

---

## Difference Between class and id

Understanding the distinction between class and id is essential:

- A **class** can be shared by multiple elements.
- An **id** must be unique and used only once per page.

IDs are commonly used for precise targeting, while classes are used for grouping.

---

## Viewing HTML Source Code

You can view the HTML of any website directly in your browser by:

- Right-clicking on the page
- Selecting **View Page Source** (Chrome)
- Or **Show Page Source** (Safari)

This allows you to inspect the actual HTML code sent by the server and rendered by the browser.

---

## Key Summary

HTML is the foundational language of the web. It defines the structure and content of web pages and works alongside CSS and JavaScript to create complete, functional websites. Browsers read HTML documents and render them into the visual pages users interact with every day.
